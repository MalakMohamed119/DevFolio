# DevFolio — Full Stack Developer Portfolio

> A clean, responsive portfolio website template built with pure HTML, CSS, and JavaScript.

🔗 **Live Demo:** [dev-folio-lac.vercel.app](https://dev-folio-lac.vercel.app)
📁 **Repository:** [github.com/MalakMohamed119/DevFolio](https://github.com/MalakMohamed119/DevFolio)

---

## 📌 About the Project

DevFolio is a fully responsive portfolio website designed for developers and creatives to showcase their work, skills, and services. Built without any frameworks — pure HTML, CSS, and JavaScript — keeping it lightweight, fast, and easy to customize.

---

## ✨ Sections

- 🏠 **Home** — Hero section with a strong personal introduction
- 👤 **About** — Personal info and skills with progress bars
- ⚙️ **Services** — Showcase of offered services (Web Design, Development, Responsive Design, etc.)
- 💼 **Work / Portfolio** — Project gallery with category filters
- ✍️ **Blog** — Latest articles and notes
- 📬 **Contact** — Contact form and location details
- 📊 **Stats Counter** — Animated counters for projects, clients, campaigns, and support hours

---

## 🚀 Getting Started

No build tools needed! Just clone and open in your browser.

```bash
# Clone the repository
git clone https://github.com/MalakMohamed119/DevFolio.git

# Navigate into the project
cd DevFolio

# Open in browser
open index.html
```

Or simply drag and drop `index.html` into your browser.

## 🎨 Customization

To make it your own:
1. Replace the name, bio, and contact info in `index.html`
2. Swap out project images in the `/images` folder
3. Update skills percentages and services to match your profile
4. Add your social media links in the footer
